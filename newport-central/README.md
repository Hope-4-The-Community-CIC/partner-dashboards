# Newport and Central PCN dashboard – v5

This version adds:
- automatic current/upcoming vs past course separation
- current and upcoming group courses plus self-guided shown as quota cards
- mini recent-uptake trend line on active cards
- change since last update
- compact waiting-list section
- past courses collapsed by default
- historic filter: last 6 months, last 12 months, all
- H4C and Hope Programme branding and copyright footer

Important:
- Self-guided already has three historic weekly points.
- Group-course history begins with the current Qualtrics snapshot. Future automated snapshots will append to each course history and create the trend automatically.
