# Newport and Central PCN dashboard

This folder replaces the current `partner-one` folder in the GitHub repository.

It contains:
- H4C and Hope Programme master logos supplied by H4C
- branded dashboard using H4C colours and Arial
- group-course quota counters
- self-guided quota counter
- optional waiting-list section

For now, the group-course values in `data.json` were taken from the uploaded Qualtrics CSV.
The next automation step is to refresh these values from the Qualtrics public CSV output and refresh the self-guided value from the Excel source.
